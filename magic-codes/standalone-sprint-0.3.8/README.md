# Standalone sprint companion 0.3.8

Exact source for the published [NRM](../../packages/Bluey-Sprint-Companion-0.3.8.nrm?raw=1). See [Bluey setup and test limits](../../docs/BLUEY-V1.md). Requires the official DKR-R 1.0.15 SDK, its supported MIPS clang/LLD and RecompModTool toolchain. Build with `python3 "$DKR_SDK/build.py" . --output <new-output-directory> --clang "$CLANG" --lld "$LLD" --mod-tool "$RECOMP_MOD_TOOL"`. The distributed NRM is the exact tested artifact; no rebuild was performed for publication.
